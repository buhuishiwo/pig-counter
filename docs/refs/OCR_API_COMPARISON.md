## 6. 关于"免费 LLM / Agent 模型"路线

评估了以下平台是否有**永久免费的多模态视觉 API**（可做 OCR）：

| 平台 | 免费模型 | 能否做 OCR |
|---|---|---|
| 硅基流动 (SiliconFlow) | Qwen2.5-7B 等文本模型免费；视觉模型（Qwen-VL）**收费** | ❌ 视觉模型不免费 |
| 阿里百炼 | qwen-vl-ocr 100 万 Token 免费（90 天），之后付费 | ⚠️ 短期免费，长期付费 |
| Google Gemini | Gemini 2.0 Flash 1,500 次/天免费 | ✅ 但需翻墙，猪场环境不可用 |
| 开源本地部署 | Qwen-VL-2B、MiniCPM-V 等 | ❌ CPU 跑不动（之前已评估） |

**结论：不存在"永久免费且不需要翻墙"的多模态视觉 API。** qwen-vl-ocr 的 100 万 Token 免费也仅限 90 天。

## 8. 结论与建议

| 维度 | 胜出 |
|---|---|
| 成本最低 | **阿里 qwen-vl-ocr**（百度的 1/23，腾讯的 1/680） |
| 手写识别最准 | **阿里 qwen-vl-ocr**（多模态理解 + 上下文判断） |
| 接入最简单 | **阿里 qwen-vl-ocr**（OpenAI 兼容，一行 `pip install openai`） |
| 数据最新可靠 | **百度 + 阿里**（均为 2026 年官方文档） |

**最终建议：阿里 qwen-vl-ocr**

比百度还便宜 23 倍，且多模态模型能区分"墙上编号"和"墙上污渍"，对猪场手写/刻划场景的适应性理论上优于纯 OCR。而且它是 OpenAI 兼容接口，代码接入最简单——改下 `base_url` 和 `model` 即可。

**次选百度**：如果对多模态模型有顾虑（幻觉、不稳定），百度传统 OCR 仍然是已验证的成熟方案，定价透明，5 元/千次对猪场成本可忽略。

**腾讯云出局**：比百度贵 30 倍，比阿里贵 680 倍，且定价数据 8 年未更新。
