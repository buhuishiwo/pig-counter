# OCR 方案选型记录 — 养殖场标记识别

**日期**: 2026-04-30
**决策者**: User + AI Agent
**状态**: 已定案

---

## 1. 需求

猪舍照片中往往包含养殖场标记信息（门牌号、栏舍编号、标识牌等），系统需要自动识别这些文字，并与已注册养殖场做匹配建议，减少用户手动选择。

---

## 2. 数据采样分析

从客户提供的 `D:\数猪系统` 五个文件夹中各取一张样图：

| 样本来源 | 标记内容 | 载体 | 字体特征 | OCR 难度 |
|---|---|---|---|---|
| 14号栏舍 | 手写 "8" | 混凝土墙面 | 粉笔/记号笔，潦草，褪色，低对比度 | ⚠️ 高 |
| 19号栏舍 | 手写 "11-23" | 混凝土墙面 | 粉笔/油漆笔，粗糙不规则 | ⚠️ 高 |
| 9号栏舍 | 刻划 "41-74" | 混凝土墙面 | 硬物划痕，靠阴影辨认，极低对比度 | 🔴 极高 |
| 3.5盘点 | "市级生猪储备基地场" + 手写数据 | 挂墙标牌 | 印刷体清晰 + 签字笔手写 | ✅ 低 |
| 生猪储备照片 | 育肥区单元编号 | 指示牌/墙面 | 印刷体为主 | ✅ 低 |

**结论**：真实数据以**手写粉笔字**和**刻划字**为主，印刷标牌没压力，但手写/刻划场景是硬骨头。

---

## 3. 约束条件

- CPU 推理
- Docker 部署，镜像体积敏感
- 免费优先
- 客户私有化部署（API 数据上传由客户自己决定）

---

## 4. 方案路线对比

| | PaddleOCR | 本地多模态 | 外部 API | **混合方案（最终选择）** |
|---|---|---|---|---|
| 手写粉笔字 | ⚠️ 大概率失败 | ⚠️ 模型 4GB+，CPU 跑不动 | ✅ | **✅ PaddleOCR 兜底 + API 接力** |
| 刻划字 | ❌ | ❌ | ⚠️ 行业难题 | ✅ **API 尝试，失败人工兜底** |
| 印刷标牌 | ✅ 99% | ✅ | ✅ | ✅ **PaddleOCR 直接吃掉** |
| 部署 | pip 一行 | 不可行 | HTTP 调用 | **pip paddleocr + openai，~2MB** |
| 费用 | 免费 | 免费 | 按量付费 | **API 部分才花钱** |

---

## 5. 最终方案：混合架构（PaddleOCR + qwen-vl-ocr）

```
图片进来
  ├→ PaddleOCR 先扫（本地，快）
  │    ├→ 置信度高 → 直接返回
  │    └→ 置信度低 / 无结果 →
  │         ├→ 调用 qwen-vl-ocr（阿里云百炼）
  │         │    └→ 有结果 → 返回
  │         └→ 仍无结果（极端刻划字）
  │              └→ 提示用户手动输入
```

**选择理由**：
1. 印刷标牌 PaddleOCR 免费搞定，不花钱
2. 手写/刻划场景 PaddleOCR 不行，本地多模态太重，外部 API 最经济
3. 选 qwen-vl-ocr 而非传统 OCR 的核心原因：多模态模型能**区分"墙上门牌号"和"墙上污渍"**，对猪场环境干扰的鲁棒性更强
4. 极端刻划字任何方案都没把握，留人工兜底

## 6. API 为什么选 qwen-vl-ocr

三条候选路线详细对比见 `docs/refs/OCR_API_COMPARISON.md`。最终选择阿里 qwen-vl-ocr：

| 维度 | qwen-vl-ocr | 百度 OCR | 腾讯云 OCR |
|---|---|---|---|
| 千次成本 | **~0.22 元** | ~5 元 | ~150 元 |
| 免费额度 | 100 万 Token（≈1,600 图），90 天 | 1,000~2,000 次/月 | 1,000 次/月 |
| 接入方式 | **OpenAI 兼容**（最简单） | SDK | SDK |
| 环境区分能力 | ✅ 可区分文字 vs 背景噪声 | ❌ | ❌ |
| 定价数据 | 2026 年官方 | 2026 年官方 | 2018 年公告 |

**价格差**：比百度便宜 23 倍，比腾讯便宜 680 倍。

## 8. API Key 归属 & 客户配合事项

采用**客户自持 Key** 模式：客户自行注册阿里云并实名认证，API Key 填入 `.env`，费用从客户账号扣除。

客户需要完成：
1. 注册阿里云账号 → 实名认证（个人支付宝扫码即可，即时完成）
2. 开通百炼服务（bailian.console.aliyun.com，点一下按钮，免费）
3. 创建 API Key（百炼控制台 → API-Key → 创建，以 `sk-` 开头）
4. 将 API Key 提供给我们填入 `.env`

**原因**：私有化部署，软件跑在客户服务器上，成本由对方兜底
