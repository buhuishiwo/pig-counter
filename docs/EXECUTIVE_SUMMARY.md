# 智慧猪群识别系统 — 功能概览

> 一页纸汇报 · 面向管理层

---

## 系统定位

基于 AI 视觉识别的**生猪盘点自动化工具**，替代传统人工逐头清点，实现拍照即出数、批量高效盘点、数据可追溯。

---

## 核心能力

| 能力 | 说明 | 价值 |
|------|------|------|
| **AI 自动识别** | 拍照上传 → 秒级返回猪只数量 | 人工清点 → 机器识别，效率提升 10 倍+ |
| **批量盘点** | 整栋/整层文件夹一键上传，自动逐栏识别 | 千头猪场 5 分钟完成盘点 |
| **标注编辑** | 识别结果可人工修正（增/删），修正后自动重编号 | 人机协同，保证准确率 |
| **数据导出** | Excel 报表一键导出，含栏舍图片和统计数据 | 直接对接盘点报表流程 |
| **历史追溯** | 统计中心查看历史记录、趋势图表、按猪场/时间筛选 | 数据积累，辅助决策 |
| **多猪场管理** | 支持多个猪场独立管理，数据隔离 | 适用于集团化运营 |

---

## 典型使用场景

1. **日常巡栏盘点**：饲养员拍照上传 → 系统自动计数 → 导出报表
2. **批量集中盘点**：管理员上传整栋照片文件夹 → 批量识别 → 下载 Excel 汇总表
3. **数据复核**：管理者进入统计中心 → 按猪场/日期查看历史数据 → 趋势分析

---

## 技术指标

| 指标 | 数据 |
|------|------|
| 单张识别速度 | < 1 秒（800×600 图片） |
| 批量处理能力 | 500 张/次，支持最多 500 张 |
| 准确率 | 置信度 80%+（常规场景） |
| 支持格式 | JPG / PNG / WEBP / BMP |
| 部署方式 | Docker 一键部署，支持本地/云端 |

## 系统架构（简）

```
用户浏览器 → Nginx → Vue 3 前端
                         ↓
                    FastAPI 后端 → ONNX 模型推理
                         ↓
                      MySQL 数据库
```
