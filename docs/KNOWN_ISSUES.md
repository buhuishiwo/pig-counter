# KNOWN_ISSUES — 已知问题

> 最后更新：2026-10-21｜以下均为**功能层**已知限制，不含运维待办（运维待办见 `wheel/TODO_LIST.md`）

## OCR 已知限制（后续优化，低优先级）

### qwen-vl-ocr 分辨率上限

qwen-vl-ocr 视觉 token 限制约 1280 个，对应约 900×900 像素。高分辨率原图（如 1706×1279）中的细小文字会被压缩后模糊，导致无法识别。

- **影响**: 部分高分辨率图片的墙面标记可能读不出来
- **缓解**: 当前实现会返回 null，走人工录入
- **后续方向**: 可考虑上传前在前端压缩图片到合理尺寸，或切片识别

### 低对比度墙面标记

部分养殖场墙面标记（粉笔字、刻划数字）与背景对比度极低，qwen-vl-ocr（当前唯一 OCR 链路，旧 PaddleOCR 已废弃）也无法识别。

- **样本**: 19号栏舍部分图片
- **影响**: 这类图片 OCR 返回 null，需人工录入
- **后续方向**: 图像预处理增强（CLAHE、锐化），或引导用户拍照时靠近标记/补光
